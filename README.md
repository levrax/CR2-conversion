# CR2 → JPEG (без потерь, как снято)

Достаёт из файлов Canon `.CR2` уже готовый JPEG, который камера записала внутрь
снимка, и сохраняет его отдельным файлом. Сжатые данные копируются **байт в
байт** — повторного сжатия не происходит, качество не теряется, работает почти
мгновенно.

Картинка получается такой, какой её отрисовала **камера**: стиль изображения,
баланс белого, контраст, шумоподавление — как снято.

Конвертеру хватает стандартной библиотеки Python; Pillow нужна, лишь если вы
захотите уменьшать или поворачивать. В том же окне есть вкладки «Отбор»,
«Обработка» и «Афиши» — см. «Вкладки окна».

**📥 Скачать готовое приложение для Windows и Mac: [INSTALL.md](INSTALL.md).**
Сборки: Windows 10/11 (64-bit) и macOS 14 Sonoma или новее (Apple Silicon и Intel);
на macOS 11–13 запускайте из исходников: `python cr2_gui.pyw`.

## Главное, что нужно знать до первого запуска

### Правки Canon DPP в результат НЕ попадают

Если вы правили снимок в Canon Digital Photo Professional (экспозиция, стиль,
кроп, поворот), DPP **не меняет сам RAW**. Она дописывает в файл «рецепт» —
список правок в закрытом формате Canon. Отрисовать рецепт умеет только движок
самой Canon; никакая программа на чистом Python, включая эту, применить его не
может и не научится.

Получить картинку, в которой правки DPP учтены, можно **только в самой DPP**:
«Конвертировать и сохранить» (Convert and save) или «Пакетная обработка»
(Batch process).

Программа лишь **сообщает**, найден ли рецепт в файле. И «найден», и «не
найден» — это утверждение о содержимом файла, а не о том, правили снимок или
нет: рецепт мог быть сохранён отдельным файлом `.vrd`/`.dr4`, правки могли быть
не сохранены вовсе, а трейлер — записан нестандартно.

### Что было измерено на ваших файлах

155 файлов из трёх реальных съёмок прочитаны и проверены:

| | |
|---|---|
| Камера | Canon EOS 550D — все 155 файлов |
| Встроенное превью | **5184 × 3456** — ровно размер кадра, у всех 155 файлов |
| Источник превью | IFD0 (штатное место), у всех 155 файлов |
| Размер превью | от 0.72 МБ до 3.43 МБ, в среднем 1.34 МБ |
| Рецепт DPP | **не найден ни в одном файле** |
| Файлы `.vrd` / `.dr4` рядом | нет |
| Canon DPP на этом компьютере | не установлена |

Из этого следует: для вашей камеры программа выдаёт **полноразмерный JPEG
18 Мп без единого пересжатия**, и применять в этих файлах попросту нечего.

Распространённое предупреждение «в CR2 лежит превью половинного размера»
**не относится к 550D** — это правда для более старых тушек (30D, 40D, 450D и
им подобных). Программа считает долю кадра для каждого файла и предупреждает,
если превью действительно мельче снимка.

### Чем результат отличается от JPEG, снятого камерой

Камера снимала RAW+JPEG, поэтому рядом с `.CR2` лежат её собственные `.JPG` —
всего 149 пар. Сравнение 30 случайных пар, попиксельно:

* размер кадра совпадает у всех 30: 5184 × 3456;
* картинка та же самая: средняя разница по пикселям 0.8–3.5 из 255
  (PSNR 34–46 дБ) — это шум JPEG-сжатия, а не другой рендер;
* **файл в 2.5–3.9 раза меньше** камерного `.JPG` (в среднем в 3.3 раза).

Причина: внутрь CR2 камера кладёт превью с меньшим битрейтом, чем отдельный
JPEG в режиме Fine. «Без потерь» здесь означает «**эта программа** ничего не
пересжимает», а не «результат равен камерному JPEG в режиме Fine».
Если вам нужен именно Fine-файл — снимайте RAW+JPEG и берите камерный `.JPG`.

## Быстрый старт

**Окно с кнопками** — двойной щелчок по `Конвертер CR2.bat`.

**Перетаскиванием** — бросьте папку или файлы `.CR2` на `Перетащи сюда CR2.bat`.
Готовые `.jpg` лягут **рядом с исходными `.CR2`**; сами `.CR2` не изменяются.
Если в имени папки есть `&` или `^`, Проводник теряет часть пути — в этом
случае перетаскивайте на `Перетащи сюда CR2.js`.

**Командная строка** — примеры ниже.

## Командная строка

Вся папка, результат рядом с исходниками:

```bash
python cr2_convert.py "D:\Фото\Съёмка"
```

Вся папка, результат в отдельную папку (безопаснее — оригиналы не трогаются):

```bash
python cr2_convert.py "D:\Фото\Съёмка" -o "D:\JPEG"
```

Посмотреть, что получится, ничего не записывая:

```bash
python cr2_convert.py "D:\Фото\Съёмка" --dry-run
```

Только эта папка, без вложенных:

```bash
python cr2_convert.py "D:\Фото\Съёмка" -o "D:\JPEG" --no-recursive
```

Отдельные файлы:

```bash
python cr2_convert.py IMG_0001.CR2 IMG_0002.CR2 -o "D:\JPEG"
```

Уменьшить до 2048 px по длинной стороне (это **пересжатие**, нужна Pillow):

```bash
python cr2_convert.py "D:\Фото" -o "D:\JPEG" --max-side 2048 --quality 90
```

Повернуть по EXIF в пиксели (тоже пересжатие, нужна Pillow):

```bash
python cr2_convert.py "D:\Фото" -o "D:\JPEG" --rotate
```

Удалить координаты GPS из результата:

```bash
python cr2_convert.py "D:\Фото" -o "D:\JPEG" --strip-gps
```

Полный список опций:

```bash
python cr2_convert.py --help
```

Коды возврата: `0` — всё хорошо, `1` — были ошибки на отдельных файлах,
`2` — неверные аргументы или не найдено ни одного `.CR2`, `130` — прервано
по Ctrl+C.

## Что программа делает и чего не делает

**Делает:**

* достаёт встроенный JPEG и сохраняет байт в байт, без пересжатия;
* переносит EXIF: Make, Model, дата съёмки, выдержка, диафрагма, ISO, фокусное
  расстояние, Orientation, реальные размеры изображения;
* переносит GPS (если не указано `--strip-gps`), ICC-профиль, XMP и миниатюру;
* переносит дату изменения файла с `.CR2` на `.jpg`;
* пишет через временный файл и `os.replace` — обрыв не оставит половину файла;
* никогда не перезаписывает существующий `.jpg` без `--overwrite`;
* сообщает, если превью меньше кадра, и на сколько;
* сообщает, если в файле найден рецепт DPP.

**Не делает:**

* не применяет рецепты Canon DPP — см. выше, это невозможно в принципе;
* не читает сайдкары `.vrd` / `.dr4` и не проверяет их наличие;
* не декодирует сам RAW (это было бы другим рендером, не камерным).
  Для файлов вообще без превью есть запасной путь через `rawpy`, если она
  установлена; по умолчанию у вас её нет, и такие файлы будут отмечены ошибкой;
* не меняет и не удаляет исходные `.CR2` — вообще никогда.

## Вкладки окна

Окно «Медиа-инструменты ЮИ РУДН»: «Конвертация» — всё описанное выше; дальше вкладки
в порядке работы: **отобрать → обработать → сделать афишу**. Им нужны библиотеки
(см. ниже), без них вместо вкладки — панель с причиной. Снимки все вкладки **только
читают**.

**«Отбор»** — делит съёмку на фрагменты события и серии, в серии выбирает самый
резкий кадр, помечает нерезкие кадры, тёмные и пересвеченные лица; «Предложить N
лучших» покрывает всё событие без двух кадров одного момента. На карточке — место по
резкости во фрагменте, пара RAW+JPEG — один кадр. Отмеченное можно скопировать в
другую папку (не в папку съёмки) и взять в «Обработку» и «Афиши». **Ничего не
удаляет и не перемещает.** Момент не оценивает: закрытые глаза и того же человека
минутой позже не видит. Лица ищет OpenCV; без него — резкость по центру кадра.

**«Обработка»** — автоулучшение (баланс белого, экспозиция, тени; лица не выбеливает),
5 фильтров, «до/после» шторкой, пресеты, пакетная обработка в папку **рядом** с
папкой съёмки («Съёмка — обработка»). EXIF сохраняется, поворот переносится в
пиксели, файлы не перезаписываются, из пары RAW+JPEG берётся JPEG. **Никакой
ИИ-ретуши**: правится кадр целиком.

**«Афиши»** — афиша A3, пост, сторис, обложка альбома, итоги и цитата по брендбуку:
фото в фирменном растре, приближение к лицу без обрезанной головы, проверка 60/30/10,
контраста и размера текста, экспорт PNG и JPEG (PDF — для A3). Кадры из «Отбора»
берутся обработанными, если прошли «Обработку». В папку со снимками и поверх чужого
снимка афиша не сохраняется. **Шрифты заменяются:** Morfin Sans в программу не
входит (лицензия не даёт права на распространение) — заголовки набраны Oswald Bold,
пока вы не укажете файл Morfin Sans. У Radiant Alt нет кириллицы: текст набран Fira
Sans Extra Condensed.

## Дополнительные библиотеки

Конвертеру — только для пересжатия; извлечение работает и без них.

Уменьшение (`--max-side`) и поворот (`--rotate`):

```bash
python -m pip install Pillow
```

Файлы, в которых превью нет совсем:

```bash
python -m pip install rawpy Pillow
```

Вкладки «Отбор», «Обработка» и «Афиши» (OpenCV нужен только поиску лиц):

```bash
python -m pip install -r requirements.txt
```

## Ограничения — без прикрас

1. **Рецепт DPP применить нельзя.** Формат закрыт. Только сама Canon DPP.
2. **Результат — превью, а не Fine-JPEG.** Тот же кадр и тот же рендер, но
   битрейт ниже: у ваших файлов в среднем в 3.3 раза меньший размер, чем у
   камерного `.JPG` (измерено на 30 парах RAW+JPEG из ваших 149).
3. **Старые камеры отдают половину кадра.** 30D, 40D, 450D и подобные. У 550D
   этой проблемы нет, но если вы принесёте чужие файлы — смотрите колонку
   «Доля кадра» и предупреждение в выводе.
4. **Перетаскивание на `.bat` пишет рядом с оригиналами.** Новые `.jpg`
   создаются в той же папке; `.CR2` не трогаются, но папка перестаёт быть
   «только фотографии». Хотите отдельно — задайте `-o` или выберите «В папку»
   в окне.
5. **Проводник ломает пути с `&` и `^` при перетаскивании на `.bat`.**
   Обойти это внутри `.bat` нельзя — используйте `.js` или командную строку.
6. **MakerNote по умолчанию не переносится.** Его внутренние смещения после
   пересборки файла указывали бы в никуда. `--keep-makernote` перенесёт его
   как есть — со всеми испорченными смещениями.
7. **EXIF не безграничен.** APP1 в JPEG не может быть больше 64 КБ. Если EXIF
   не помещается, программа выбрасывает самые крупные необязательные теги и
   пишет об этом; обязательные съёмочные теги сохраняются.
8. **Повёрнутые снимки.** Превью в CR2 лежит горизонтально, поворот описан
   тегом EXIF Orientation — он переносится. Любой нормальный просмотрщик
   повернёт картинку сам. `--rotate` запечёт поворот в пиксели, но это уже
   пересжатие.
9. **Без превью — без результата.** Если превью в файле нет и `rawpy` не
   установлена, файл будет отмечен ошибкой, а не тихо пропущен.
10. **Для окна нужен tkinter.** Он входит в стандартный установщик Python для
    Windows, но если Python собирали без него — `Конвертер CR2.bat` покажет
    сообщение и запишет причину в `cr2_gui_error.log` рядом с собой.
    Командная строка при этом продолжит работать.
