# Зависимости времени выполнения для конвертера CR2.
#
# ВАЖНО: из исходников программа работает БЕЗ них.  Основной режим — извлечение
# готового JPEG из CR2 без перекодирования — написан на чистой стандартной
# библиотеке.  Pillow нужен только для поворота/уменьшения извлечённого кадра,
# rawpy (+ numpy) — только для проявки RAW, когда встроенного JPEG в файле нет.
# Нет пакета — соответствующий режим просто выключен, окно открывается и работает.
#
# В СОБРАННОМ приложении всё иначе: пользователь не может доустановить пакет в
# .exe или .app, поэтому для сборки (cr2app.spec / build_local.py) все три
# обязательны — иначе получится дистрибутив с половиной возможностей.
#
# Установка:  python -m pip install -r requirements.txt
#
# Сам PyInstaller сюда НЕ входит: это инструмент сборки, а не зависимость
# приложения — от него не зависит ни одна строка кода, и пользователю готовой
# сборки он не нужен вовсе.  Ставится отдельной командой:
#     python -m pip install pyinstaller
# Закреплять его версию, если понадобится, следует в отдельном
# requirements-dev.txt, а не здесь: иначе кэш и окружение выполнения начнут
# зависеть от версии сборщика.

# Поворот, уменьшение, повторное сжатие извлечённого кадра.
Pillow>=10.0.0

# Проявка RAW, когда встроенного JPEG нет (обёртка над LibRaw).
#
# Три строки вместо одной из-за macOS на Intel.  Начиная с 0.26 rawpy
# публикует для macOS ТОЛЬКО колёса macosx_11_0_arm64; на x86_64 pip уходит в
# сборку из исходников, которой нужен LibRaw, а его на раннере нет — и rawpy
# просто не ставился.  Раньше это глушилось в CI одним ::warning::, и Intel-
# сборка молча выходила без режима проявки RAW, отличаясь от arm64 только
# суффиксом в имени файла.  0.25.0 — последняя версия с колесом
# macosx_10_9_x86_64 для cp312 (проверено по PyPI).
#
# Условия взаимоисключающие: pip берёт ровно одну строку и остальные пропускает.
rawpy>=0.22.0,<0.26; sys_platform == "darwin" and platform_machine == "x86_64"
rawpy>=0.22.0; sys_platform == "darwin" and platform_machine != "x86_64"
rawpy>=0.22.0; sys_platform != "darwin"

# Тянется rawpy как зависимость; закреплён явно, потому что от него зависит
# размер сборки (в колесе для Windows лежит OpenBLAS на 21 МБ) и потому что
# numpy 2.x потребовал отдельной поддержки в хуках PyInstaller.
numpy>=1.26.0
