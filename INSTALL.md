# Как скачать и установить

Готовое приложение не требует Python: всё нужное уже внутри. Есть сборки для
Windows и для Mac.

## 1. Какой файл нужен

| Компьютер | Файл |
|---|---|
| Windows 10 или 11, 64-bit | `…-windows-x64.zip` |
| Mac с чипом Apple M1, M2, M3, M4 | `…-macos-arm64.zip` |
| Mac с процессором Intel | `…-macos-x86_64.zip` |

**Как узнать, какой у вас Mac:** значок яблока в левом верхнем углу экрана →
«Об этом Mac». Строка «Чип: Apple M…»
значит arm64, строка «Процессор: … Intel» значит x86_64. В том же окне видна
версия macOS: нужна **macOS 14 Sonoma или новее**, на более старых приложение не
запустится.

## 2. Где скачать

### Способ А. Страница релизов — для всех

1. Откройте <https://github.com/levrax/CR2-conversion/releases/latest>.
2. Внизу, в разделе **Assets**, нажмите на архив под ваш компьютер.

Вход в GitHub не нужен. Если страница пустая или пишет «There aren't any
releases», версия ещё не выпущена — используйте способ Б.

### Способ Б. Свежая сборка из Actions — для проверки новых изменений

1. Войдите в GitHub: без входа файлы здесь не скачиваются.
2. Откройте <https://github.com/levrax/CR2-conversion/actions> и выберите
   верхний запуск **с зелёной галочкой**.
3. Внизу страницы, в разделе **Artifacts**, скачайте `CR2-windows-x64`,
   `CR2-macos-arm64` или `CR2-macos-x86_64`.
4. Это **архив в архиве**: распакуйте скачанный файл, внутри будет нужный `.zip`.

Такие сборки хранятся **14 дней**, потом ссылка пропадает.

## 3. Установка на Windows

1. Правый клик по архиву → **«Извлечь всё…»**. Запускать прямо из архива нельзя.
2. Положите папку `CR2 Converter` куда удобно, например в «Документы».
3. Откройте папку и запустите **`CR2 Converter.exe`**.
4. При первом запуске Windows может показать «Система Windows защитила ваш
   компьютер». Нажмите **«Подробнее»** → **«Выполнить в любом случае»**.
   Приложение без платной цифровой подписи, поэтому Windows его не узнаёт.
5. Ярлык на рабочий стол: правый клик по `CR2 Converter.exe` → «Отправить» →
   «Рабочий стол (создать ярлык)».

Папка `_internal` рядом с `.exe` обязательна: без неё приложение не запустится.
`CR2 Converter CLI.exe` — версия для командной строки, двойным щелчком её
запускать не нужно.

## 4. Установка на Mac

1. Двойной щелчок по архиву — появится **`CR2 Converter.app`**.
2. Перетащите его в папку **«Программы»**.
3. Запустите. Mac скажет, что не может проверить разработчика: приложение без
   платной подписи Apple. Откройте **«Системные настройки» → «Конфиденциальность
   и безопасность»**, пролистайте вниз и нажмите **«Всё равно открыть»**. Это
   нужно сделать один раз.

Если Mac пишет, что приложение «повреждено», выполните в «Терминале» и
запустите снова:

```bash
xattr -dr com.apple.quarantine "/Applications/CR2 Converter.app"
```

## 5. Первый запуск

Вверху окна четыре вкладки: **Конвертация, Отбор, Обработка, Афиши**. Что делает
каждая — в [README](README.md#вкладки-окна).

Шрифт заголовков Morfin Sans в приложение не входит: его лицензия не разрешает
распространять файл. Если он у вас есть, во вкладке «Афиши» нажмите «Указать
файл Morfin Sans». Без него заголовки набираются шрифтом Oswald.

## 6. Обновление

**Windows.** Настройки хранятся в файле `cr2_gui_settings.json` прямо в папке
приложения. Перед заменой папки новой версией скопируйте этот файл и положите
его обратно в новую папку, иначе настройки сбросятся.

**Mac.** Замените `CR2 Converter.app` в «Программах» новым. Настройки хранятся
отдельно, в `~/Library/Application Support/CR2 Converter`, и сохранятся сами.

## 7. Если не запускается

- **Windows, ничего не происходит.** Проверьте, что архив распакован целиком и
  рядом с `.exe` есть папка `_internal`. Если в папке приложения появился
  `cr2_gui_error.log`, в нём причина.
- **Mac, приложение сразу закрывается.** Проверьте версию macOS: нужна 14 или
  новее. Журнал ошибок: `~/Library/Application Support/CR2 Converter/cr2_gui_error.log`.
- **Mac на macOS 11–13.** Готовая сборка не подойдёт. Можно запустить из
  исходников: поставьте Python 3.12 с <https://www.python.org>, на странице
  репозитория нажмите **Code → Download ZIP**, распакуйте и в «Терминале» в этой
  папке выполните `python3 cr2_gui.pyw`. Без дополнительных библиотек работает
  только «Конвертация»; остальным вкладкам нужна команда
  `python3 -m pip install -r requirements.txt`, и на старой macOS часть библиотек
  может не установиться.
